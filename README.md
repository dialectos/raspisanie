# Расписание

Один статический сайт: `index.html`, `style.css`, `script.js`. Никаких библиотек, npm или сборки.

## Публикация на GitHub Pages

1. Создай репозиторий на GitHub.
2. Загрузи `index.html`, `style.css` и `script.js` **в корень репозитория**.
3. В **Settings → Pages** выбери **Deploy from a branch**, ветку **main** и папку **/(root)**.
4. После публикации GitHub выдаст адрес сайта.

## Как работает

- На экране сразу **среда и четверг**, без навигации по дням.
- Переключатель «Верхняя / Нижняя» позволяет посмотреть другой тип недели.
- При открытии выбирается неделя с **ближайшими занятиями**: после последней пары четверга автоматически отображается следующая неделя. Так, воскресенье 8 ноября 2026 показывает верхнюю неделю 9–14 ноября.
- Во время занятий текущая пара подсвечивается словом «Сейчас», ближайшая следующая — «Далее». Если время до начала ближайшей пары ещё не наступило, отметка «Далее» появляется у неё.
- В настройках можно включить показ понедельника, вторника, пятницы и субботы и сменить тему.
- Настройки автоматически сохраняются через `localStorage`.
- Дата и время берутся по часовому поясу `Asia/Chita`.

## Время пар

1. 08:30–10:05
2. 10:15–11:50
3. 12:35–14:10 (перерыв 11:50–12:35)
4. 14:20–15:55

Интервалы определены в массиве `PERIODS` в `script.js`.

## Чередование

`09.11.2026` — начало верхней недели. Каждые 7 дней верхняя и нижняя чередуются. При переносах, каникулах или изменениях календаря потребуется поправить исходный код.

## Редактирование расписания

Занятия находятся в объекте `LESSONS` в `script.js`. `upper` — верхняя неделя, `lower` — нижняя. `2` — среда, `3` — четверг. В `period` указывается номер пары от 1 до 4, `title` — название предмета, `type` — вид занятия, `room` — аудитория, `building` — корпус (при необходимости).
